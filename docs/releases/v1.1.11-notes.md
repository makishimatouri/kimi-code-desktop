# Kimi Code Desktop v1.1.11

## 修复项目整组归档

- 项目归档改为按真实 `workDir` 查找磁盘上的全部 session，不再受搜索过滤、active/archived 列表或分页状态影响。
- Rust 后端在写入前统一检查项目内是否存在 busy session，避免项目只归档一部分。
- 项目归档和恢复都使用同一条整组状态更新链路，并补充项目目录匹配与列表一致性测试。

## 其他说明

- 保留 Apple Silicon、Intel、Windows 产物和 macOS 12 最低版本要求。
- 桌面端仍要求用户单独安装并配置 Kimi Code CLI。
- 如果没有 Apple Developer ID 签名与公证凭据，macOS 包仍按 ad-hoc 或未签名模式发布。
