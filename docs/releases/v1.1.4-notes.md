# Kimi Code Desktop v1.1.4

## 本地会话与工作区恢复修复

- 启动时从 Kimi CLI 的本地 `agents/main/wire.jsonl` 回放已有会话历史，恢复用户消息、思考、正文、工具调用和工具结果。
- 从 session `state.json` 的 `cwd`，以及 `session_index.jsonl`、`workspaces.json` 中识别已有项目目录。
- ACP 的 session/list 不可用时，继续使用本地会话和工作区数据；打开已有 session 不再要求先连接 ACP。
- 保持 Apple Silicon、Intel、Windows 产物和 macOS 12 最低版本要求不变。

## 使用说明

- 桌面端仍要求用户单独安装并配置 Kimi Code CLI。
- 如果没有 Apple Developer ID 签名与公证凭据，macOS 包仍按 ad-hoc 或未签名模式发布。
