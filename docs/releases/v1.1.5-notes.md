# Kimi Code Desktop v1.1.5

## Windows 跨平台测试修复

- 修复 Windows runner 上本地会话工作目录测试夹具未正确转义反斜杠的问题。
- 保持从 session `state.json`、`session_index.jsonl`、`workspaces.json` 和本地 wire 历史恢复会话与项目目录的行为。
- 保持 Apple Silicon、Intel、Windows 产物和 macOS 12 最低版本要求不变。

## 使用说明

- 桌面端仍要求用户单独安装并配置 Kimi Code CLI。
- 如果没有 Apple Developer ID 签名与公证凭据，macOS 包仍按 ad-hoc 或未签名模式发布。
