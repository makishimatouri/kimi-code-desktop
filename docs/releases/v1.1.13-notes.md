# Kimi Code Desktop v1.1.13

## 修复项目文件夹归档

- 项目归档和恢复会先读取 active 与 archived 中的完整 session 列表，再按真实 `workDir` 筛选项目成员。
- 项目操作复用单个 session 的归档接口，不再依赖批量项目 IPC 扫描结果。
- 已经处于目标状态的 session 会跳过，项目中存在 busy session 时，其他可编辑 session 仍会继续处理。
- 归档、恢复完成后会同步刷新 active 与 archived 列表。

## 说明

- 归档只修改 session 状态，不会移动、删除或修改项目文件夹。
- Kimi Code CLI 仍需单独安装并配置。
