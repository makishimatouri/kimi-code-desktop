# Kimi Code Desktop v1.1.8

## 修复旧版 macOS WebView 点击 session 报错

- 修复 Intel Mac 上点击包含 Mermaid 图表的 session 时，旧版 WebKit 因不支持 Mermaid 正则语法而导致页面崩溃的问题。
- 在不支持 Mermaid 所需正则特性的 WebView 中，Mermaid 内容降级为可读的普通代码块，不影响 session 历史消息加载。
- 支持 Mermaid 的现代 WebView 继续使用图表渲染。

## 其他说明

- 保留 v1.1.7 的 session 历史回放修复、工作区识别和 Intel macOS 支持。
- 桌面端仍要求用户单独安装并配置 Kimi Code CLI。
- 如果没有 Apple Developer ID 签名与公证凭据，macOS 包仍按 ad-hoc 或未签名模式发布。
