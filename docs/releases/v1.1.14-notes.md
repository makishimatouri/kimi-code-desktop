# Kimi Code Desktop v1.1.14

## 修复项目文件夹归档

- 点击项目文件夹的归档按钮时，会先弹出确认提示。
- 确认后按 session 保存的真实 `workDir` 查找该项目下的全部 active 和 archived session，并统一归档或恢复。
- 项目中仍有 session 时也可以直接执行项目级归档，不需要先逐个归档 session。
- 存在 busy session 时，busy session 保持不变；其他可编辑 session 继续处理，并保留现有错误提示和部分成功行为。
- 归档或恢复完成后同步刷新 active、archived 和项目分组列表，避免旧结果覆盖最新状态。

## 其他

- 保留 session 右键菜单：复制完整 ID、复制前 6 位短 ID、重命名、归档或恢复、删除。
- 归档只修改 session 状态，不会移动、删除或修改项目文件夹。
- Kimi Code CLI 仍需单独安装并配置。
- macOS Intel 与 Apple Silicon 继续分别提供原生 DMG；签名和公证状态以随包 manifest 为准。
