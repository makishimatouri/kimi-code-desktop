# Kimi Code Desktop v1.1.7

## 修复 session 历史消息为空

- 修复桌面端多 session 编排器在 React 渲染阶段提前创建 runtime 后，跳过首次启动和历史回放的问题。
- 现在即使 `actionsFor()` 先于 `attach()` 创建 session runtime，首次进入 session 仍会执行本地历史回放。
- 保留现有 session、工作区、ACP-only 运行时和 Intel macOS 支持。

## 使用说明

- 桌面端仍要求用户单独安装并配置 Kimi Code CLI。
- 如果没有 Apple Developer ID 签名与公证凭据，macOS 包仍按 ad-hoc 或未签名模式发布。
