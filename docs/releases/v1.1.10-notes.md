# Kimi Code Desktop v1.1.10

## 修复会话归档与右键菜单

- 修复归档列表预加载与归档操作同时发生时的刷新竞态，归档、批量归档、恢复和批量恢复后的 active / archived 列表保持一致。
- 修复过期刷新结果覆盖最新会话列表的问题。
- 为会话条目增加右键菜单，支持复制完整会话 ID、复制前 6 位短 ID、重命名、归档或恢复以及删除。
- 支持点击外部区域或按 `Escape` 关闭右键菜单，并在窗口边界附近自动调整菜单位置。

## 其他说明

- 保留 Apple Silicon、Intel、Windows 产物和 macOS 12 最低版本要求。
- 桌面端仍要求用户单独安装并配置 Kimi Code CLI。
- 如果没有 Apple Developer ID 签名与公证凭据，macOS 包仍按 ad-hoc 或未签名模式发布。
