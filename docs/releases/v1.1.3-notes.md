# Kimi Code Desktop v1.1.3

## macOS CLI 路径修复

- macOS 启动时自动搜索官方 Kimi Code CLI 安装器使用的 `~/.kimi-code/bin`。
- 修复从 Finder 启动桌面端时能找到 `kimi` 命令但无法执行 `kimi --version` 和 `kimi acp` 的问题。
- 保持 Apple Silicon、Intel、Windows 产物和 macOS 12 最低版本要求不变。

## 使用说明

- 首次启动仍要求用户单独安装并配置 Kimi Code CLI。
- 如果没有 Apple Developer ID 签名与公证凭据，macOS 包仍按 ad-hoc 或未签名模式发布。
