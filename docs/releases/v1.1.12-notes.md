# Kimi Code Desktop v1.1.12

## 修复项目整组归档

- 修复按项目分组归档或恢复时只更新当前列表、项目内其他 session 没有同步的问题。
- 项目归档现在按真实 `workDir` 扫描本地全部 session，不受搜索、active/archived 列表或分页状态影响。
- 兼容旧版 `kimi.json`、新版 `workspaces.json`，以及 session 中的 `cwd`、`workDir`、`work_dir` 字段。
- 归档刷新增加竞态保护，归档后会话会稳定出现在“已归档”列表中。

## 其他修复

- 会话右键菜单支持复制完整 ID、复制短 ID、重命名、归档/恢复和删除。
- 保留 Apple Silicon、Intel 和 Windows 产物；macOS 最低版本为 12.0。
- 没有 Apple 签名与公证凭据时，macOS 产物继续使用 ad-hoc 或未签名模式，并在 manifest 中标注。
- 桌面端仍要求用户单独安装并配置 Kimi Code CLI。
