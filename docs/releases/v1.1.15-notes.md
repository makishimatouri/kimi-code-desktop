# Kimi Code Desktop v1.1.15

## 修复项目文件夹归档

- 点击项目文件夹的归档按钮时，会先显示应用内确认框，不再依赖 macOS WebView 不稳定的系统确认框。
- 确认后按 session 保存的真实 `workDir` 查找该项目下的全部 session，并一次性归档；项目中仍有 session 时不需要先逐个归档。
- 归档过程中显示忙碌状态，防止重复提交；完成后刷新 active、archived 和项目分组列表。
- 若没有任何 session 被更新，或操作失败，会显示明确提示；项目文件夹本身不会被移动、删除或修改。

## 其他

- 保留 session 右键菜单：复制完整 ID、复制前 6 位短 ID、重命名、归档 / 恢复和删除。
- 忙碌 session 继续遵守现有保护规则，其他可编辑 session 可以部分成功处理。
- macOS Intel 与 Apple Silicon 继续分别提供原生 DMG；签名和公证状态以随包 manifest 为准。没有 Apple signing secrets 时使用 ad-hoc / unsigned 降级构建。
- Kimi Code CLI 仍需单独安装并配置。
