# Kimi Code Desktop v1.1.9

## 修复 Intel Mac 点击 session 报错

- 修复旧版 macOS WebKit 对 Mermaid 11 的 Unicode 属性与复杂 lookbehind 正则支持不完整时，兼容性探测误判的问题。
- 在不支持 Mermaid 实际运行时语法的 WebView 中，进入 session 前就把 Mermaid fenced block 降级为普通代码块，避免加载 Mermaid 组件时报 `Invalid regular expression`。
- 保留现代 WebView 的 Mermaid 图表渲染能力。

## 其他说明

- 保留 v1.1.8 的 session 历史回放、工作区识别和 Intel macOS 支持。
- 桌面端仍要求用户单独安装并配置 Kimi Code CLI。
- 如果没有 Apple Developer ID 签名与公证凭据，macOS 包仍按 ad-hoc 或未签名模式发布。
