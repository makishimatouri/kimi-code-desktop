# Kimi Code Desktop v1.1.2

## macOS Intel 支持

- 新增 Intel Mac 原生 `x86_64-apple-darwin` 构建和 DMG 产物。
- 保留 Apple Silicon `aarch64-apple-darwin` DMG、Windows MSI 和原有 ACP-only 运行时。
- macOS 支持范围保持为 macOS 12 及以上版本。
- macOS manifest 会记录目标架构、签名模式、公证状态、DMG 布局模式和 SHA-256 校验值。

## 下载与首次启动

- Intel Mac 下载名称包含 `_x64.dmg`。
- Apple Silicon Mac 下载名称包含 `_aarch64.dmg`。
- 如果 Release 没有配置 Apple Developer ID 签名与公证凭据，DMG 会使用 ad-hoc 或未签名模式构建；首次启动可能需要在 macOS“隐私与安全性”中手动允许。
- 桌面端仍要求用户单独安装并配置 Kimi Code CLI，运行时通过 `kimi acp` 提供会话、模型和工具能力。
